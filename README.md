# CliniTech – Smart Hospital ERP System

CliniTech is an AI-integrated Hospital ERP solution designed to modernize healthcare operations through intelligent automation, predictive analytics, and seamless user experience. The system brings together core hospital functions into a centralized platform for enhanced efficiency, transparency, and patient satisfaction.

## 🔧 Core Features

### 1. User Management & Final Bill Prediction
- Secure role-based access for patients, doctors, and administrators.
- ML-powered final bill prediction based on treatment history, diagnostics, and hospital stay.
- Personalized user dashboards.

### 2. Drug Inventory Management
- Real-time tracking of drug stocks across departments.
- AI-powered demand forecasting to reduce waste and prevent shortages.
- Alerts for stock expiry and low inventory.

### 3. Bill & Payment Management
- Automated invoice generation and multi-mode payment support.
- Integration with insurance claim processing.
- Real-time payment tracking and notifications.

### 4. Patient History Analysis & Prediction
- AI-driven analysis of medical history and vital records.
- Predictive alerts for health risks and personalized care recommendations.
- Support for early intervention and preventive healthcare.

## 🚀 Technologies Used
- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Python (Flask/Django)
- **Machine Learning**: scikit-learn, pandas
- **Database**: MySQL / PostgreSQL
- **Security**: JWT Authentication
- **Deployment**: (Optional: Docker, Heroku, etc.)
